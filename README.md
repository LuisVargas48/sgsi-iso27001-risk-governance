# sgsi-iso27001-risk-governance
Diseño e implementación de un SGSI empresarial alineado a ISO/IEC 27001:2022, COBIT y NIST CSF. Incluye evaluación de riesgos, BCP/DRP, matriz RASCI, catálogo de 25 políticas de seguridad y cumplimiento normativo (GDPR) para una organización global del sector automotriz.
